# 媒体图床管家

SillyTavern 第三方 UI 扩展：分类扫描并更新正则里的图片与 MP3 链接。

## 功能

- 界面只保留“角色卡 / 世界书 / 小手机 / 美化”四个来源分类
- 角色卡包含角色正则、描述、开场白、头像与角色资源；小手机相关正则和世界书条目会单独归入“小手机”
- 扫描 SillyTavern 中已导入的全部外置世界书，并支持定位、备份和一键替换其中的媒体链接
- 扫描时逐张加载完整角色卡，包含未打开角色的局部正则
- 识别完整 URL、`//` 协议相对地址、站内相对路径和只有文件名的图片/MP3 引用，过滤 CSS、JS 与普通网页链接
- 只有文件名的引用会按文件名反查已扫描到的完整 URL；仅在结果唯一时自动关联，避免误配同名文件
- 图片预览、MP3 播放与加载状态检测
- 默认只展示无法加载的问题，加载正常的图床不会占用列表
- 同一链接引用超过 20 处时自动放入“已忽视”，可切换查看
- 字体链接默认不展示，仅在“美化”分类中保留
- 每个问题都可展开查看具体角色卡、正则或世界书条目及字段路径
- 相同 URL 自动归组，可全部替换或只替换勾选位置
- 按“旧地址前缀 → 新地址前缀”批量迁移当前筛选分类
- 写入前自动下载 JSON 备份
- 所有处理均在浏览器本地完成

## 安装

将整个目录放入 `SillyTavern/data/<你的用户>/extensions/third-party/sillytavern-image-host-manager/`，然后重载 SillyTavern。

也可以先把本目录发布为 Git 仓库，再在“扩展 → 安装扩展”中粘贴仓库 URL。

## 使用

1. 在扩展菜单点击“媒体图床管家”。
2. 选择来源、媒体类型和加载状态。
3. 展开查看角色卡或来源、正则名称、字段用途和路径。
4. 输入新 URL 替换，或使用新旧前缀批量迁移。

“预设”分类对应当前正在使用的生成预设；“外置世界书”会扫描世界书列表中的全部文件，不限于当前启用的文件。

角色头像、描述与开场白、内嵌世界书和角色资源使用只读定位模式：可以检测、预览并显示具体字段，但需在 SillyTavern 的角色编辑器中修改；头像失效时需重新上传。角色卡正则、外置世界书、美化与当前预设支持一键替换。

插件不会上传角色卡内容；预览图片时，浏览器会像普通网页一样访问对应图片地址。
