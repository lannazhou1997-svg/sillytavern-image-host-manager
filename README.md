# 角色卡图床管家

SillyTavern 第三方 UI 扩展：扫描并更新不同角色卡“局部正则”中的图片链接。

## 功能

- 扫描全部角色卡的 `data.extensions.regex_scripts`
- 展示角色卡、正则名称、字段位置和用途
- 图片预览并标记无法加载的链接
- 单条填写新 URL，或按“旧地址前缀 → 新地址前缀”批量迁移
- 写入前自动下载原始正则 JSON 备份
- 所有处理均在浏览器本地完成

## 安装

将整个目录放入 `SillyTavern/data/<你的用户>/extensions/third-party/sillytavern-image-host-manager/`，然后重载 SillyTavern。

也可以先把本目录发布为 Git 仓库，再在“扩展 → 安装扩展”中粘贴仓库 URL。

## 使用

1. 在扩展菜单点击“角色卡图床管家”。
2. 查看角色名、正则名、字段用途、原链接和预览。
3. 为单条记录填写新 URL，或输入旧、新地址前缀批量迁移。
4. 取消不想修改的项目，点击“备份并更新”。

插件不会上传角色卡内容；预览图片时，浏览器会像普通网页一样访问对应图片地址。
