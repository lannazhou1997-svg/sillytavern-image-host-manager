# 媒体图床管家

SillyTavern 第三方 UI 扩展：分类扫描并更新正则里的图片与 MP3 链接。

## 功能

- 按“角色头像 / 角色卡正则 / 描述与开场白 / 内嵌世界书 / 角色资源 / 美化 / 当前预设”分类
- 扫描时逐张加载完整角色卡，包含未打开角色的局部正则
- 只收录常见图片格式和 MP3，过滤 CSS、JS 与普通网页链接
- 图片预览、MP3 播放与加载状态检测
- 相同 URL 自动归组，可全部替换或只替换勾选位置
- 按“旧地址前缀 → 新地址前缀”批量迁移当前筛选分类
- 写入前自动下载 JSON 备份
- 所有处理均在浏览器本地完成

## 安装

将整个目录放入 `SillyTavern/data/<你的用户>/extensions/third-party/sillytavern-image-host-manager/`，然后重载 SillyTavern。

也可以先把本目录发布为 Git 仓库，再在“扩展 → 安装扩展”中粘贴仓库 URL。

## 使用

1. 在扩展菜单点击“媒体图床管家”。
2. 选择来源、媒体类型和加载状态。
3. 展开查看角色卡或来源、正则名称、字段用途和路径。
4. 输入新 URL 替换，或使用新旧前缀批量迁移。

“预设”分类对应当前正在使用的生成预设。

角色头像、描述与开场白、内嵌世界书和角色资源使用只读定位模式：可以检测、预览并显示具体字段，但需在 SillyTavern 的角色编辑器中修改；头像失效时需重新上传。角色卡正则、美化与当前预设仍支持一键替换。

插件不会上传角色卡内容；预览图片时，浏览器会像普通网页一样访问对应图片地址。
